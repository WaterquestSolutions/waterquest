- Start with the movement, then build the circuit
- A simple movement sequence
- Define the source and the receiving side of every flow path
- Distinguish pressure limitation from motion control
- Account for unequal cylinder volumes
- Integrate stored energy only where its function is defined
- Place fluid management within the architecture
- Instrument the boundaries that matter
- Review interfaces with the controls and process equipment
- Commission the sequence, not just the pump
- Design the return path with the supply path
