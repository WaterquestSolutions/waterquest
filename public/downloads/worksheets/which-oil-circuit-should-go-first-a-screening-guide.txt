REVIEW THE TOPIC
Use these guide sections to check the entries above. Record unresolved items; do not turn an unknown value into an assumed rating.
- Start where oil removal solves a visible problem
- Two renewal candidates, one useful comparison
- Start with consequence and the actual release route
- Examine product and process sensitivity separately
- Treat heat and fire exposure with care
- Check whether the mechanical duty fits
- Include the support system in feasibility
- Use renewal timing to improve the decision
- Compare candidates without false numerical precision
- Turn the leading candidate into a bounded evaluation
- Prioritize exposure rather than applying a blanket rule
- Turn this guidance into a project decision
