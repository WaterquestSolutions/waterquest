Three decisions before equipment is released

Read the decision checklist
StageRequired recordDecision
DefineDuty, site conditions, interfaces and scope boundaryIs the proposed equipment a credible candidate?
SelectExact configuration, revisioned drawings, operating limits, materials and approval routeDoes the evidence satisfy the specified duty and interfaces?
AcceptAgreed FAT/SAT, as-built records, instructions, spares, training and closed deviationsCan the owner operate and maintain the installation as agreed?

Separate evidence types

A catalogue value supports screening. A configuration drawing defines an interface. A certificate applies only to the named product and scope. A witnessed test demonstrates the specified test conditions. Keep these records distinct in the project register.
