Understand the selection

Read the code. Define the valve.

01

Identify the function

The two-digit valve type describes the hydraulic function.

02

Match actuation and return

Actuation and return each have a defined position in the ordering sequence.

03

Confirm compatibility

A code describes a configuration; it does not establish that every possible combination is available.

Code structure

Understand each position.

Pressure class
1: below 30 bar / 2: up to 160 bar
Special relief classes
3: special range / 4: 25–100 bar; confirm configuration
Mounting
No letter: stand-alone / M: manifold / C: CETOP 3
Port-size letters
A: 3 / B: 6 / C: 9 / D: 12 / E: 16 / F: 25 / G: 38 mm
Fluid letters
O: other / S: seawater / T: technical water / W: tap water
Return S
Spring return only

Selection considerations

  • An actuation card is a separate item for solenoid configurations that require one.
  • Use the product page’s listed ordering options and confirm mounting, fluid and actuation compatibility.
