Valve Ordering Guide

What it does: Helps identify the valve function, actuation and configuration for an enquiry.

Where it’s used: Water hydraulic circuits requiring defined movement, holding and control.

Why water: Use control components designed for the working water and selected circuit.

Understand each position.

Special relief classes

No letter: stand-alone / M: manifold / C: CETOP 3

Identify the function

02

Match actuation and return

Actuation and return each have a defined position in the ordering sequence.

03

Confirm compatibility

A code describes a configuration; it does not establish that every possible combination is available.

Define the integration and commissioning boundary

Interface to settleRequired evidence
Hydraulic functionValve function, normal and failure state, flow range, differential pressure and backpressure.
Electrical / pilot actuationExact coil or pilot supply; voltage, current or pressure; frequency where applicable; duty and connector.
Control and feedbackCommand type, I/O list, position/pressure feedback, interlocks, timeout and fault response.
Mechanical installationApproved port/manifold pattern, dimensions, orientation, fasteners and environmental enclosure.
Commissioning and handoverParameter record, approved schematic/wiring revision, measured response and acceptance limits.

Confirm compatibility for the selected valve and control configuration. A product family name does not establish interchangeable wiring, pilot requirements or a complete safety function.
